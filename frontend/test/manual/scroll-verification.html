🔍 修复详情

问题原因

CSS overflow: hidden 配置冲突，阻止了子元素的滚动功能。

修复方法

将 overflow: hidden 改为 overflow-x: hidden; overflow-y: auto

修复示例 (index.css line 53): /* 修复前 */ .app-body { overflow: hidden; /* ❌ 阻止所有滚动 */ } /* 修复后 */ .app-body { overflow-x: hidden; /* ✅ 只阻止横向滚动 */ overflow-y: auto; /* ✅ 允许纵向滚动 */ }
