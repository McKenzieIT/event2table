## 项目背景

### 迁移动机

1. **双轨制维护成本高**: 同时维护REST和GraphQL两套API,开发效率低
2. **性能瓶颈**: REST API存在N+1查询问题,性能不佳
3. **技术负债累积**: 废弃API未清理,代码库混乱
4. **用户体验差**: 多次请求获取数据,响应慢

### 迁移目标

- 完全移除REST API双轨制
- 统一使用GraphQL API
- 提升系统性能50%以上
- 清理所有技术负债
- 建立完善的文档和工具体系
