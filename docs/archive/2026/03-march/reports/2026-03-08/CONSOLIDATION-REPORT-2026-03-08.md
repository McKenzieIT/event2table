## 二、新增经验点总结

### 2.1 性能优化经验（8个）

1. **并行执行优化策略** ⚠️ P0
   - 70%性能提升（串行12小时 → 并行3.5小时）
   - 独立任务并行执行，依赖任务串行执行
   - 使用Claude Code Subagent并行执行

2. **DataLoader批量查询优化** ⚠️ P0
   - 查询减少70-99%（101次 → 2次）
   - API响应时间90%提升（500ms → 50ms）
   - 双层缓存（L1: 60秒，L2: 300秒）

3. **前端React性能优化** ⚠️ P0
   - 重渲染减少50-70%
   - useMemo、useCallback、React.memo优化
   - 计算密集型操作缓存

4. **批量操作优化** ⚠️ P0
   - executemany替代循环execute
   - 数据库往返100→1（99%减少）
   - 事务开销99%减少

5. **双层缓存架构设计** ⭐ P1
   - L1缓存（内存，60秒）
   - L2缓存（Redis，300秒）
   - 缓存命中率85%+

6. **游戏统计查询合并** ⭐ P1
   - JOIN查询替代N+1查询
   - 201次 → 1次查询（99.5%减少）
   - API响应2326倍提升（2000ms → 0.86ms）

7. **TTL分层设置策略** ⚠️ P0
   - 静态数据：1800秒（30分钟）
   - 半静态：600秒（10分钟）
   - 动态：120秒（2分钟）
   - 实时：60秒（1分钟）

8. **Entity架构下的性能优化** ⭐ P1
   - 预加载Entity，避免重复转换
   - 缓存命中率>95%
   - 性能提升2-3x
