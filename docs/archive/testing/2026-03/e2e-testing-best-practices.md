# E2E 测试最佳实践

> 从 E2E 测试实施中总结的经验

## 测试策略

### 1. 测试组织
- 按功能模块组织测试
- 使用 Page Object Model
- 分离测试数据和测试逻辑

### 2. 测试稳定性
- 使用 waitUntil 替代固定等待
- 避免硬编码的选择器
- 实现测试数据清理机制

### 3. Chrome DevTools MCP 集成
- 使用 MCP 进行手动测试验证
- 自动化测试与手动测试结合
- 记录测试执行日志

### 4. 测试报告
- 生成详细的测试报告
- 失败测试截图
- 测试覆盖率统计

## 常见问题解决

### 问题 1: 测试不稳定
**解决方案**: 
- 增加合理的等待时间
- 检查元素可见性
- 使用重试机制

### 问题 2: 测试数据污染
**解决方案**:
- 每个测试使用独立数据
- 测试后清理数据
- 使用事务回滚
